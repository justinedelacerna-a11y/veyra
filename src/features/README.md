# Feature Modules

This directory contains domain-driven feature modules for the Veyra platform.

Each feature folder encapsulates its own domain-specific components, hooks, types, and logic:
- `vehicles/` — Fleet browsing, details, specifications, and filtering.
- `booking/` — Reservation flow, checkout, pricing calculation, and confirmation.
- `fleet-ops/` — Vehicle assignment, check-in/out, inspection, and maintenance tracking.
- `customer-portal/` — Account profile, active bookings, history, and verification documents.
